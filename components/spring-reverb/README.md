# spring-reverb (work in progress)

Functional model of Accutronics / Belton style spring reverb tanks (`spring_reverb.sub`).

**Not finished:** there are no `.asy` symbols, no bench script and no demo schematic yet, so this component
has not been verified the way the others have. Do not rely on it.

## References

The model was written from these publications. They are linked, not copied:

- CE Distribution, "Spring Reverb Tanks Explained and Compared":
  https://www.cedist.com/tech-articles/spring-reverb-tanks-explained-and-compared
- Accutronics application notes (1999): theory of operation, drive and recovery circuits, input/output
  impedance chart, RT60 decay chart, product specification. Public URL still to be located.
